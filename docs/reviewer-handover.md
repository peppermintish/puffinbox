Universal audio GET/HEAD now delivers a source that fits the client's declared containers, codecs, bitrate, and channel limits. Numeric playback-session IDs retain device and user ownership. In the source preview, unchanged official web decoded the original FLAC fixture, paused at 14.062585 seconds, and saved that exact position after stopping. Universal transcoding, positive start offsets, richer music behavior, and normal desktop acceptance remain open.

The latest local source and container results are recorded in acceptance.md: 227 standard Rust tests, 22 PostgreSQL integration cases plus one recorder unit test, 32 Python tests, and 26 container checks.
