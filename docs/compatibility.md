# Capability and validation matrix

Puffinbox is partial and unreleased. Local source and container checks on 2026-10-02 passed; their scope and reproduction steps are in [acceptance.md](acceptance.md). Passing checks for individual paths does not establish a complete Jellyfin replacement.

## Current-source gates

The Rust workspace passes formatting, strict Clippy, and 227 standard tests. All 22 PostgreSQL integration cases and the database-backed recorder unit test passed against a disposable database. All 40 Python checks passed; browser and book-reader regressions cover unchanged interface code. The Live TV synchronization fix passes with ordinary and delayed response bodies. Current core image `87a1da1a` passed all 26 HTTP, audio, HLS credential, filter, socket, and restart acceptance checks. The 29 isolated HTTPS proxy checks apply to earlier core `b023b350`; they have not been repeated on this latest image. Earlier source and scratch-container TLS checks passed; the TLS transport code is unchanged.

The MIT/Apache-2.0 Cargo allowlist passes without exceptions. Linked Rust Unicode tables carry Unicode-3.0; the libc, unwind, compiler-builtins, and startup audit remains incomplete. See [licensing.md](licensing.md). No release tag or archive has been created. [Both cloud CI jobs passed at `0b0d44c`](https://github.com/peppermintish/puffinbox/actions/runs/36935798608), including transport-counter markers, the HLS rename fix, delayed Live TV responses, and the private Linux HTTPS fixture. [Both cloud jobs also passed at `1bf5b2a`](https://github.com/peppermintish/puffinbox/actions/runs/36939097957), including native audio selection, [at `e72cfbd`](https://github.com/peppermintish/puffinbox/actions/runs/36942840169), including explicit SDR conditions, and [at `69e26db`](https://github.com/peppermintish/puffinbox/actions/runs/36946522847), including readiness recovery and the GNU entry checker. A newer [shared-runtime experiment](../experiments/linux-gnu-runtime/README.md) passed 25 container and 29 local HTTPS checks, including restart and resume, plus numerical comparisons. It removes known retained runtime sections and generated Unicode definitions from a separate executable; inlined provenance, external-runtime distribution, and production adoption remain open.

## Jellyfin API target

The target is the public [Jellyfin 12.0.0 OpenAPI document](https://repo.jellyfin.org/releases/openapi/stable/jellyfin-openapi-12.0.json). The [route report](generated-api-route-coverage.md) finds 92 exact method/path declarations among 364 operations. This counts declarations, not compatible behavior. Response semantics, query combinations, errors, and client expectations must be tested separately.

## Requested scope

| Area | Current behavior | Remaining limits |
| --- | --- | --- |
| Playback and transcoding | Device-profile negotiation, original-file streaming and byte ranges, playback progress/resume, full-duration H.264/AAC HLS for known-duration media, job cancellation and graceful restart. The 25-check container run covers synthetic MP4 and MKV files, nonsequential segments, source timestamps, notifications, and the final segment boundary. | FFmpeg/ffprobe are external. Full-duration HLS is limited to four hours and 2 GiB per session without cache eviction. Broad codecs, audio continuity across batches, track changes, hardware acceleration, and native clients remain unvalidated. |
| Subtitles | Embedded text extraction and selected subtitle delivery are covered by synthetic HLS acceptance. | Broader subtitle formats, styling, seeking, and client track switching need acceptance. Earlier visible desktop cues apply only to their old test image. |
| Multi-user access | Sessions, revocation, administrator actions, library visibility, parental categories, playback/download policy, private playlists, and per-user/client preferences have PostgreSQL coverage. New users default to remote access disabled. | Preferences persist, but not every playback and view setting is applied yet. Local PIN authentication is unavailable. External security review and broad client behavior remain unvalidated. |
| Remote access | Public origin, trusted proxies, secure cookies, CORS, and remote-access policy are configurable. A local TLS proxy fixture passed 29 checks, including certificate trust, forwarding spoof prevention, and active-session policy changes. Its Linux certificate ownership fix passed locally and in cloud CI with private file permissions. Compose publishes to loopback by default. | Internet access, broader proxy configurations, and external security review remain unvalidated. |
| Metadata | Local NFO and bounded provider/catalog paths, refresh jobs, stored artwork metadata, and permission-aware genre/tag/rating/year filters. Real NFO values and provider precedence have database coverage; official web combined genre, tag, and year selections. | Stream-language choices and Live TV classification filters are unsupported. Menus have a 4,096-choice bound. Provider coverage and artwork workflows are limited. TVmaze attribution display remains unvalidated. |
| Live TV/DVR | IPTV sources, guide/catalog state, policies, schedules, recording lifecycle, retries, and concurrent timer ownership have database coverage. | Physical tuners, real providers, long recordings, recovery under faults, and native clients need acceptance. |
| DLNA | SSDP discovery and bounded ContentDirectory behavior have local tests. | AVTransport, renderer control, DLNA transcoding, physical devices, IPv6 discovery, and broad interoperability are incomplete. |
| Plugins | Bounded Wasm extensions and plugin persistence have local coverage. | Jellyfin .NET plugins are unsupported. A full extension ecosystem and external plugin acceptance are incomplete. |
| Music | Audio catalog/playback and private ordered playlists; the bundled browser can create, edit, reorder, remove, and play queues. Standard item queries list owned playlists at the root or within a visible music library containing one of their visible tracks. Details, owner permissions, saved queue order, paging, name/date sorting, search, and atomic single/bulk deletion have PostgreSQL coverage. Universal audio GET/HEAD uses probed direct formats and limits, with private file delivery and byte ranges. Opaque playback IDs are scoped to the authenticated user, device, and server run. Official web decoded a synthetic FLAC track in the source preview and saved its stopped position. | Universal audio requires an explicit container list and zero start offset. Its transcoding fallback, sample-rate/bit-depth limits, alternate sources, and remote media are unavailable. Broader music codecs, audible continuity, mixed catalog types, playback/metadata filters, sharing, video playlists, richer music metadata, and normal desktop playlist acceptance remain open. Empty playlists appear in root queries. Legacy user item queries and the earlier playlist collection/deletion extensions remain available. |
| Photos | Safe raster preview, download headers, and offline packages. | The official desktop photo query fails with 400 for `Filters=IsNotFolder`; native viewing has not passed. Broad photo management and thumbnails remain incomplete. |
| Books | A bounded PDF/EPUB reader with library, parental, and download policy checks; 8 Node reader cases pass. | PDF assets exclude non-allowlisted CMaps/fonts/decoders. Some PDFs cannot render fully. EPUB media, annotations, DRM, conversion, and broad client support are incomplete. |
| Offline sync | Browser-origin IndexedDB transfers with chunk and whole-file SHA-256, interrupted resume, cached streaming, ranges, and account-change handling. | Copies belong to the browser/site origin. Real storage pressure, eviction, cross-device sync, and external clients need acceptance. Server deletion does not erase a downloaded copy. |
| Deployment | A static Linux server image, external PostgreSQL, and a separately assembled FFmpeg test runtime. Active HLS shutdown and resume passed on the current image. | Whole-runtime license closure and production operations remain open. |
| Official clients | Official web browses, filters, plays HLS, seeks, and resumes, with authenticated user-data notifications. In an isolated official Qt 6 desktop profile using unchanged official 12.1 web files, native MPV decoded visible SDR frames and seeks against core `570d3c7f`. Against current core `87a1da1a`, it resumed at 93.208 seconds after container recreation, completed the video, and recorded it played. Native HLS decoded visible frames with selected AAC, initialized Windows audio output, and accepted pause/progress events. The prior image also completed synthetic FLAC and saved a longer track's stopped position. | Native audio resume, HLS stop, listening acceptance, broad codecs, track changes, and audio continuity remain unvalidated. Photo viewing currently fails on an unsupported item filter. A transient official-web playback notice remains unresolved. Range conditions support only Equals/NotEquals for explicitly signalled SDR; HDR and other profile conditions remain incomplete. The installed Qt 5 client's earlier blank captures are separate observations. |
| Scale | Bounded [20,000- and 99,000-file scanner runs](scanner-scale.md) passed exact catalogue and stale-cleanup checks. The larger run indexed 99,775 rows in 39.364 seconds with 31.69 MiB peak server RSS. | Empty-file indexing on one local host does not support a 1 PB library, billions of files, or thousands of concurrent streams. |

## Licensing closure

Project-authored code and original adapters are MIT OR Apache-2.0. Bundled browser assets have their own accepted notices. Cargo license closure passes; runtime closure does not. External PostgreSQL, FFmpeg distributions, and metadata data have separate boundaries. See [the licensing inventory](licensing.md) and [release gates](release-gates.json).

Earlier source checkpoints and image-specific client observations are recorded in [validation-history.md](validation-history.md). They do not validate the current source.
