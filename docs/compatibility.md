# Capability and validation matrix

Puffinbox is partial and unreleased. Local source and container checks through 2026-10-03 passed; their scope and reproduction steps are in [acceptance.md](acceptance.md). Passing checks for individual paths does not establish a complete Jellyfin replacement.

## Current-source gates

The Rust workspace passes formatting, strict Clippy, and 234 standard tests. All 22 PostgreSQL integration cases, the database-backed recorder unit case, and 72 Python checks passed. Current core image `6f0ac6fb` passed all 28 container and 29 isolated HTTPS checks, including bounded universal AAC conversion, scoped credentials and revocation, playlist sharing, HLS resume, active shutdown, restart, sockets, and saved progress. Official Jellyfin web converted an original synthetic AIFF source through fragmented MP4 to its end; the desktop played the same source directly through EOF. Each accepted all four playback events, and separate reads confirmed completion and increased play counts. The old web playback error and all image-specific evidence remain in [acceptance.md](acceptance.md). Earlier browser and book-reader checks cover unchanged product interface code. Audible quality and broader native format coverage remain unvalidated. Cloud CI for this audio-conversion change is pending; the earlier `ecc0fd2` workflows passed before these application changes. The older `9f307b1` Chromium failure retains an unknown cause because its detailed logs returned 403. TLS transport code is unchanged.

The MIT/Apache-2.0 Cargo allowlist passes without exceptions. Linked Rust Unicode tables carry Unicode-3.0; the libc, unwind, compiler-builtins, and startup audit remains incomplete. See [licensing.md](licensing.md). No release tag or archive has been created. [Both cloud CI jobs passed at `0b0d44c`](https://github.com/peppermintish/puffinbox/actions/runs/36935798608), including transport-counter markers, the HLS rename fix, delayed Live TV responses, and the private Linux HTTPS fixture. [Both cloud jobs also passed at `1bf5b2a`](https://github.com/peppermintish/puffinbox/actions/runs/36939097957), including native audio selection, [at `e72cfbd`](https://github.com/peppermintish/puffinbox/actions/runs/36942840169), including explicit SDR conditions, and [at `69e26db`](https://github.com/peppermintish/puffinbox/actions/runs/36946522847), including readiness recovery and the GNU entry checker. ## Jellyfin API target

The target is the public [Jellyfin 12.0.0 OpenAPI document](https://repo.jellyfin.org/releases/openapi/stable/jellyfin-openapi-12.0.json). The [route report](generated-api-route-coverage.md) finds 95 exact method/path declarations among 364 operations. This counts declarations, not compatible behavior. Response semantics, query combinations, errors, and client expectations must be tested separately.

## Licensing closure

Project-authored code and original adapters are MIT OR Apache-2.0. Bundled browser assets have their own accepted notices. Cargo license closure passes; runtime closure does not. External PostgreSQL, FFmpeg distributions, and metadata data have separate boundaries. See [the licensing inventory](licensing.md) and [release gates](release-gates.json).

GNU audit server `65f20a63` passed all 27 container and 29 HTTPS checks with hashes for every mapped source path. Its 220 registry archives match the lockfile, and native traces preserve temporary OpenSSL inputs before cleanup. These source snapshots do not clear individual-file exceptions, generated inputs, unmapped content, headers, or external-runtime distribution. The [runtime audit](runtime-link-audit.md#dependency-and-native-compiler-source-snapshots) records the exact boundary; production remains the static image.

Earlier source checkpoints and image-specific client observations are recorded in [validation-history.md](validation-history.md). They do not validate the current source.
