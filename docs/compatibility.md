# Capability and validation matrix

Puffinbox is partial and unreleased. Local source and container checks through 2026-10-03 passed; their scope and reproduction steps are in [acceptance.md](acceptance.md). Passing checks for individual paths does not establish a complete Jellyfin replacement.

## Current-source gates

The Rust workspace passes formatting, strict Clippy and 251 standard tests. All 23 PostgreSQL integration cases, two database-backed unit cases and 92 Python checks passed on the current source snapshot. Core `1e024f35` passed 33 container and 29 local HTTPS checks, including active FFmpeg shutdown, video resume and embedded metadata persistence after restart. The retained client backend preserved its identity, grants, media state, playlist catalog and studio favorites through the upgrade. Both official web and Qt 6 Desktop displayed tagged titles and disc groups and completed the four-track original FLAC album queue, with one added play per track and zero saved music resume. Web active audio and Desktop audio EOF were observed. Exact web request options returned byte-identical original FLAC files. Audible quality, wider formats and native final-position reliability remain unvalidated. Twenty-four independent studio requests and favorite persistence across restart passed on preceding core `3f06f4ac`.

On preceding core `3f06f4ac`, official web and Qt 6 Desktop displayed the three local NFO studios and Beta Film Studio's two movies with the default folder sort. Web's studio favorite control toggled on and off. Web then fetched the first short movie's HLS video and saved completion, with three successful playback responses; no video frame was observed and its player page was blank after EOF. Desktop playback failed in video-output initialization. A separate Direct3D control stalled with MPV uninitialized; OpenGL profiles, including shorter-path, full-kit and software-Chromium controls, remained blank at startup. These scoped results are recorded in [acceptance.md](acceptance.md). Visual playback, general Desktop startup and normal EOF navigation remain unresolved on this fixture.

Earlier album playback, guest artist mixes, resume and other client results retain their image-specific scopes in [acceptance.md](acceptance.md). Public observations of an isolated official Jellyfin 12.0.0 server support the [music-state policy](jellyfin12-playback-behavior.md), [artist roles and counts](jellyfin12-music-credits.md), [embedded fields](jellyfin12-embedded-audio.md) and [studio contract](jellyfin12-studios.md). Bounded embedded title, album, date, genre and track/disc imports now run automatically after music scans. Credits resolve only to existing visible same-library artists. Automatic tag-named artist and album creation, embedded images, ambiguous names, explicit PlayCount writes, native AAC, audible quality, wider formats, longer converted sources, arbitrary native seeking and complete recommendation behavior remain incomplete or unvalidated. Native final-position inconsistency remains unexplained. [Both main jobs passed at `39a1f4b`](https://github.com/peppermintish/puffinbox/actions/runs/37102079631), as did [both GNU TLS modes](https://github.com/peppermintish/puffinbox/actions/runs/37102079578); those results precede the embedded-audio change.

The MIT/Apache-2.0 Cargo allowlist and selected-source guards pass without exceptions. The known futures-channel BSD queue is replaced with an original synchronized queue; other individual-file inputs remain under review. Linked Rust Unicode tables carry Unicode-3.0. Libc, unwind, compiler-builtins and startup review remains incomplete. The separate GNU candidate `2df83ea9` passed source inventory, numerical and TLS checks, 31 container checks and 29 HTTPS checks, using external runtime infrastructure. Its external standard library must not be bundled, and complete retained-input review and production adoption remain open. See [licensing.md](licensing.md) and [the runtime audit](runtime-link-audit.md). No release tag or archive has been created.

The current build excludes OpenSSL's separately noticed SipHash implementation by disabling both SipHash and internal QUIC. The old binary and first single-option build fail the exclusion check; combined-option source, static container and GNU `e02164b6` pass. The latter also passes native source capture, mapped-source inspection, compiler-notice, numerical and certificate checks, without whole-runtime clearance or production adoption. [Both main jobs passed at `3caf504`](https://github.com/peppermintish/puffinbox/actions/runs/37098193385), as did [both GNU TLS modes](https://github.com/peppermintish/puffinbox/actions/runs/37098193395); those cloud results precede the exclusion change.

## Jellyfin API target

The target is the public [Jellyfin 12.0.0 OpenAPI document](https://repo.jellyfin.org/releases/openapi/stable/jellyfin-openapi-12.0.json). The [route report](generated-api-route-coverage.md) finds 106 exact method/path declarations among 364 operations. This counts declarations, not compatible behavior. Response semantics, query combinations, errors, and client expectations must be tested separately.

## Licensing closure

Project-authored code and original adapters are MIT OR Apache-2.0. Bundled browser assets have their own accepted notices. Cargo package audits and the known-source replacement guard pass; complete file-level and runtime license review remains open. External PostgreSQL, FFmpeg distributions, and metadata data have separate boundaries. See [the licensing inventory](licensing.md) and [release gates](release-gates.json).

GNU audit server `65f20a63` passed all 27 container and 29 HTTPS checks with hashes for every mapped source path. Its 220 registry archives match the lockfile, and native traces preserve temporary OpenSSL inputs before cleanup. These source snapshots do not clear individual-file exceptions, generated inputs, unmapped content, headers, or external-runtime distribution. The [runtime audit](runtime-link-audit.md#dependency-and-native-compiler-source-snapshots) records the exact boundary; production remains the static image.

Earlier source checkpoints and image-specific client observations are recorded in [validation-history.md](validation-history.md). They do not validate the current source.
