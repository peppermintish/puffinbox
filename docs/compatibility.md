# Capability and validation matrix

Puffinbox is partial and unreleased. Local source and container checks through 2026-10-04 passed; their scope and reproduction steps are in [acceptance.md](acceptance.md). Passing checks for individual paths does not establish a complete Jellyfin replacement.

## Current-source gates

Physical music albums now use a single agreed current embedded album name from
tracks the user can access. NFO titles take precedence; empty, malformed, stale
or conflicting tags retain the folder name. Item IDs and saved state survive
renaming. Two details, 24 ordered/paged reads and ten artist-scoped searches match the
original public reference; combined Ids/SearchTerm selection remains qualified.
See [physical album names](jellyfin12-embedded-audio.md#physical-album-names).

PostgreSQL SCRAM now sends an empty username field and preserves the startup
role. The selected Linux production, build and test graphs exclude stringprep
and its Unicode dependencies. A real PostgreSQL regression covers Unicode and
punctuation roles, wrong passwords, missing roles and altered server signatures.
Password normalization and TLS behavior are unchanged. See [the driver scope](licensing.md#postgresql-scram-username).

MIME extension lookup now uses an original ASCII comparator with the unchanged MIT upstream table. Full-table and served-header checks pass; ordinary ASCII extensions remain case-insensitive, including on Unicode filenames. Non-ASCII suffixes are unknown. Removing unicase narrows the generated-data inventory; [historical MIME inputs and whole-runtime licensing](licensing.md) remain open.

Plugin staging now requires compiled WebAssembly. The original hook has database and container coverage, including rejection of renamed text, restart persistence and hidden output after disablement. Disabling the text compiler removes its Unicode width tables from the locked graph; [other runtime licensing limits](licensing.md) remain open.

The public [item refresh route](jellyfin12-item-refresh.md) now queues independent local metadata and image work. Ten request-binding observations, five existing-album metadata modes and the complete recorded album projection match the isolated Jellyfin 12 reference. Duplicate work, permissions, replacement options and sidecar cleanup have PostgreSQL coverage. Recursive refresh, complete validation, remote providers, image-mode equivalence, trickplay and broader item types remain incomplete or unvalidated.

The Rust workspace passes formatting, strict Clippy and 258 standard tests.
All 26 PostgreSQL integration cases and three database-backed unit cases passed;
119 Python tests passed and three compiler-dependent tests were skipped. Core
`aa0e55dc`, operator `3d385fef` and server `523c195b` passed 35 container and 29
local HTTPS checks, including active FFmpeg shutdown, video resume and saved
metadata/user-data after restart. The retained client backend kept its identity,
grants, all 50 returned item user-data rows, playlists, studio favorites and
original media hashes without a reset. Both official web and Qt 6 Desktop
displayed the renamed album and completed its four-track FLAC queue with automatic
advancement, fifteen successful reports each and one added play per track per
client. Desktop audio EOF and advancing web audio were observed. Joined evidence
binds 402 source fingerprints. Audible quality, wider formats, general native
video acceptance and native final-position reliability remain unvalidated.
The complete runtime license review remains open.

## Jellyfin API target

The target is the public [Jellyfin 12.0.0 OpenAPI document](https://repo.jellyfin.org/releases/openapi/stable/jellyfin-openapi-12.0.json). The [route report](generated-api-route-coverage.md) finds 107 exact method/path declarations among 364 operations. This counts declarations, not compatible behavior. Response semantics, query combinations, errors, and client expectations must be tested separately.

## Licensing closure

Project-authored code and original adapters are MIT OR Apache-2.0. Bundled browser assets have their own accepted notices. Cargo package audits and the known-source replacement guard pass; complete file-level and runtime license review remains open. External PostgreSQL, FFmpeg distributions, and metadata data have separate boundaries. See [the licensing inventory](licensing.md) and [release gates](release-gates.json).

GNU audit server `65f20a63` passed all 27 container and 29 HTTPS checks with hashes for every mapped source path. Its 220 registry archives match the lockfile, and native traces preserve temporary OpenSSL inputs before cleanup. These source snapshots do not clear individual-file exceptions, generated inputs, unmapped content, headers, or external-runtime distribution. The [runtime audit](runtime-link-audit.md#dependency-and-native-compiler-source-snapshots) records the exact boundary; production remains the static image.

Experimental GNU candidate `94f7a1e4` uses external C case-conversion functions and passed its full byte/EOF fixture, source and notice checks, 35 container and 29 HTTPS checks. Both official clients completed its original four-track album with fifteen successful playback responses each and one added play per track. Testing used explicit external runtime mounts; the static backend was then restored, with all 50 saved rows matching observed plays. The new preprocessor replay omits the previous character macro candidate, while the socket declaration macro and wider header/runtime review remain open. These results do not clear licensing or imply production adoption. See [the runtime audit](runtime-link-audit.md#external-c-character-conversion).

Earlier source checkpoints and image-specific client observations are recorded in [validation-history.md](validation-history.md). They do not validate the current source.
